BEFORE YOU GET IN TOUCH

A few fair questions.

Do I need a new website?+

Usually, the aim is to improve the site you already have. Oscar first needs to check the platform, access and whether it supports the proposed setup.

What will it cost each month?+

The proposed model separates setup, vendor costs and optional support. Actual software and message charges depend on the tools and volume. They must be itemised in the written quote before you commit. This differs from the current care-plan wording and needs approval.

Will this bring me more visitors?+

This service improves the enquiry route for people already visiting your website. It does not promise additional traffic, rankings or a particular number of jobs.

Do you answer my enquiries for me?+

You or your team respond to the customer. This setup routes their request to you; it is not an emergency answering or dispatch service.

Can you help with reviews or a new website too?+

Oscar’s existing Quotehelm offer also lists reviews, booking, chat and website services. This proposed homepage leads with enquiry capture so we can start by identifying the most useful change. See the current full price list.
